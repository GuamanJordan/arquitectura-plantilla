# Movil Java y .NET

## Android Java

Ruta:

```text
clientes/movil-android-java
```

Usa Android SDK y Java. No usa Dart ni Flutter.

## .NET MAUI Android

Ruta:

```text
clientes/movil-dotnet-maui
```

Target:

```text
net10.0-android
```

En emulador Android, usar `10.0.2.2` para acceder al `localhost` de la computadora anfitriona.
