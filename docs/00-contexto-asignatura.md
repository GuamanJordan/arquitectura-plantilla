# Contexto de la asignatura

Esta plantilla cubre los bloques iniciales de Arquitectura de Software:

- Java y .NET como lenguajes principales.
- SOA orientado a APIs.
- RESTful como estilo arquitectonico.
- SOAP como protocolo de interoperabilidad.
- gRPC como RPC moderno.
- Clientes de consola, escritorio, web y movil.
- Bases de datos MariaDB, MySQL y SQL Server.
- Servidores Payara, GlassFish e IIS para escenarios Windows.

Dart y Flutter no se usan en los clientes moviles.
